# C# Daily Log - 13/06

## What I Worked On

Today I completed my first fully playable Snake game in C# using the console.

### Features Implemented

* Snake movement using WASD controls
* Random apple spawning
* Score system
* Growing tail mechanic
* Wall collision detection
* Self-collision detection
* Game reset after death
* Real-time game loop

## Concepts Learned

### Object-Oriented Programming

* Working with custom classes (`Coord`)
* Constructors
* Properties
* Methods
* Enums for movement directions

### Collections

* Using `List<Coord>` to store snake position history
* Understanding how the snake tail is created and updated

### Object Comparison

* Learned why comparing objects with `==` does not work as expected
* Studied and implemented `Equals()`
* Learned how value comparison differs from reference comparison

### Game Development Fundamentals

* Game Loop structure
* Frame timing
* Keyboard input handling
* Collision systems
* Coordinate-based movement

## Biggest Challenges

* Understanding how `Equals()` works internally
* Learning how the snake tail follows the head
* Understanding how position history is stored and updated
* Debugging coordinate comparisons

## Key Takeaway

Today was the first time I built a complete game from start to finish. This project helped me connect many C# concepts together and gave me a much better understanding of how real applications are structured internally.
