# C# Roadmap: Beginner to Advanced

## Phase 1 - Foundations 

Goal: Become comfortable writing small applications without tutorials.

Topics:

* Variables and data types
* Operators
* Conditionals (if, switch)
* Loops (for, while, foreach)
* Methods
* Arrays
* Lists
* Strings
* Basic debugging

Projects:

* Calculator
* Number guessing game
* RPG battle simulator
* Tic-Tac-Toe

---

## Phase 2 - Object-Oriented Programming (Current Stage)

Goal: Think in objects and relationships.

Topics:

* Classes
* Objects
* Constructors
* Encapsulation
* Properties
* Static members
* Inheritance
* Polymorphism
* Abstraction
* Interfaces

Projects:

* RPG with multiple character classes
* Inventory system
* Library management system
* Pokémon-style battle simulator

---

## Phase 3 - Intermediate C#

Goal: Learn how real C# applications are structured.

Topics:

* Enums
* Structs
* Events
* Delegates
* Action and Func
* Exceptions
* Generics
* Collections
* File handling
* Serialization (JSON)

Projects:

* Save/Load system for RPG
* To-Do application
* Banking simulator
* Contact manager

---

## Phase 4 - Data Structures & Algorithms

Goal: Become a stronger problem solver.

Topics:

* Big O notation
* Stacks
* Queues
* Linked Lists
* Trees
* Dictionaries
* Hash Tables
* Searching algorithms
* Sorting algorithms
* Recursion

Projects:

* Custom data structure implementations
* Mini search engine
* Pathfinding visualizer

---

## Phase 5 - Desktop Development

Goal: Create graphical applications.

Topics:

* WPF
* XAML
* MVVM

* Commands
* UI Design

Projects:

* Tic-Tac-Toe WPF

Goal: Understand modern C# deeply.

Topics:

* LINQ

* Tasks

* Dependency Injection
* Design Patterns
* Garbage Collection
* Memory Management

Projects:

* File scanner

* Concurrent task manager

## Phase 7 - Databases

Goal: Persist real data.

Topics:

* SQL
* Relational databases
* Entity Framework Core
* Migrations

Projects:

* Student management system

## Phase 9 - Professional Development

Goal: Write production-quality software.

Topics:

* Unit Testing

## Phase 10 - Expert Level

Goal: Understand how the language and runtime work internally.

Topics:

* CLR
* IL (Intermediate Language)
* JIT Compiler
* Memory Internals
* Advanced Multithreading
* Performance Optimization
* Source Generators

Projects:

* Custom framework components
