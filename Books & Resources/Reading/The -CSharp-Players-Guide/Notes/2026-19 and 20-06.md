# C# Notes — Loops, Arrays & Methods

## 🔁 Loops

### `while`

* Repeats while a condition is `true`.
* Checks the condition **before** each iteration.

```csharp
while (condition)
{
    // code
}
```

### `do...while`

* Executes the code **at least once**.
* Checks the condition **after** the first iteration.

```csharp
do
{
    // code
}
while (condition);
```

### `for`

* Best when the number of iterations is known.

```csharp
for (int i = 0; i < 10; i++)
{
    // code
}
```

Structure:

* Initialization
* Condition
* Update

### `foreach`

* Used to iterate through every element in a collection.
* Simpler and more readable than `for`.
* Cannot modify the collection through the loop variable.
* Does **not** provide the index.

```csharp
foreach (int number in numbers)
{
    Console.WriteLine(number);
}
```

### `break`

Stops the loop immediately.

```csharp
if (input == "exit")
    break;
```

### `continue`

Skips the rest of the current iteration and starts the next one.

```csharp
if (number == 12)
    continue;
```

# 📦 Arrays

An array stores multiple values of the **same type**.

```csharp
int[] numbers = new int[5];
```

Initialize with values:

```csharp
int[] numbers = { 1, 2, 3, 4, 5 };
```

Access an element:

```csharp
numbers[0]
```

Modify an element:

```csharp
numbers[2] = 10;
```

Get the array size:

```csharp
numbers.Length
```

Loop through an array:

```csharp
for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
```

Or:

```csharp
foreach (int number in numbers)
{
    Console.WriteLine(number);
}
```

### Copying Arrays

```csharp
for (int i = 0; i < source.Length; i++)
{
    destination[i] = source[i];
}
```

### Finding the Smallest Value

```csharp
int smallest = int.MaxValue;

foreach (int number in numbers)
{
    if (number < smallest)
        smallest = number;
}
```

### Calculating an Average

```csharp
int total = 0;

foreach (int number in numbers)
{
    total += number;
}

float average = (float)total / numbers.Length;
```

### Useful Syntax

Last element:

```csharp
numbers[^1]
```

Range:

```csharp
numbers[1..^1]
```

---


# 💡 Key Takeaways

* Use `for` when you need the index.
* Use `foreach` when you only need the values.
* Arrays store fixed-size collections of the same type.
* Methods improve readability, reuse, and organization.
* Recursive methods replace certain loops by solving a smaller version of the same problem until reaching a base case.
