Summary

Today I learned about the switch statement and the modern switch expression in C#. They provide a cleaner alternative to long chains of if and else if statements when comparing a single value against multiple possible cases.

What I Learned
A switch is ideal when comparing one variable against many different values.
break prevents execution from continuing into other cases.
default works similarly to the final else in an if statement.
Multiple case labels can execute the same block of code.
A switch expression returns a value, making code shorter and easier to read.
Reflection

At first, I thought every decision could be solved with if statements. After studying this chapter, I realized that switch often produces cleaner and more readable code when handling menus or fixed options.

I also learned that good programming is not only about making code work, but also about choosing the most appropriate control structure for each situation.
