# ⚙️ Methods

Methods organize code into reusable blocks.

Basic structure:

```csharp
ReturnType MethodName(parameters)
{
    // code
}
```

Example:

```csharp
void SayHello()
{
    Console.WriteLine("Hello!");
}
```

Method with parameters:

```csharp
void Greet(string name)
{
    Console.WriteLine($"Hello {name}");
}
```

Method that returns a value:

```csharp
int Add(int a, int b)
{
    return a + b;
}
```

Calling a method:

```csharp
int result = Add(5, 3);
```

### Local Methods

Methods can be declared inside another method.

```csharp
static void Main()
{
    void Print()
    {
        Console.WriteLine("Hello");
    }

    Print();
}
```

### Recursive Methods

A recursive method calls itself.

It always needs:

* A **base case** (stopping condition).
* A recursive call that gets closer to the base case.

Example:

```csharp
void Countdown(int number)
{
    if (number < 1)
        return;

    Console.WriteLine(number);
    Countdown(number - 1);
}
```

### Factorial Example

```csharp
int Factorial(int number)
{
    if (number == 1)
        return 1;

    return number * Factorial(number - 1);
}
```

The recursive calls are placed on the call stack and resolved from the base case back to the first call.
