Summary

Today I studied one of the most important topics in programming: decision making.

Until now, my programs executed instructions sequentially. This chapter introduced conditional logic, allowing programs to choose different execution paths based on specific conditions.

New Concepts Learned
Variables declared inside a block only exist within that block (scope).
The final else statement is optional.
A single if without braces only controls the next statement, which can easily lead to bugs.
Decision trees can be represented using chained if / else if statements.
Conditions always evaluate to a bool (true or false).
