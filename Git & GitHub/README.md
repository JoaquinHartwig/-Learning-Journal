# Git & GitHub Learning Journey

## About

This section documents my journey of learning Git and GitHub while I continue developing my programming skills.

As I build projects in C#, and later in other languages, I want to gradually improve my understanding of version control and professional development workflows.

My goal is not only to write code, but also to learn how to manage, organize, maintain, and track software projects in a professional way.

---

## Why I Am Learning Git

Git is one of the most important tools used by software developers around the world.

Learning Git will help me:

* Track changes in my projects.
* Safely experiment with new features.
* Maintain a history of my progress.
* Organize my development workflow.
* Collaborate with other developers in the future.
* Build professional habits early in my learning journey.
