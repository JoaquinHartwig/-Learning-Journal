# English Grammar in Use

## 📖 About this Book

**English Grammar in Use** by Raymond Murphy is my main grammar resource for learning English.

After finishing the MATLAB documentation, I realized that I wanted to strengthen my understanding of English grammar instead of relying only on exposure through technical reading.

My goal is not just to understand grammar rules, but to develop the ability to **read, write, think, and communicate naturally in English**.

---

## 🎯 Goals

- Build a solid foundation in English grammar.
- Improve my writing skills.
- Better understand technical books and documentation.
- Develop the habit of thinking in English.
- Apply grammar naturally while reading programming books.

---

## 📚 Study Method

For each unit I will:

- Read the explanation carefully.
- Complete all exercises.
- Write my own example sentences.
- Review new grammar concepts.
- Apply what I learned while reading technical books.
