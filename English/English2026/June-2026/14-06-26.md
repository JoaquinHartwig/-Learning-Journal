Words and concepts learned
 
* devices → dispositivos / devices.
* arrange → organizar / ordenar.
* spent → gastado / dedicado (irregular past of spend).
* improved → mejorado (past of improve).
* supplied → suministrado / proporcionado.
* tune → afinar / ajustar.
* interface → interfaz (can also be used as a verb: to interface with).
* boldface → negrita / bold text.
* forward → adelante / siguiente.
* surrounding → circundante / que rodea.
* higher up → más arriba / en una posición superior.
* networking → redes / comunicación en red.
