Words and concepts learned

* put it to use → ponerlo en uso / utilizarlo (expresión idiomática).
* looks back at → mira hacia atrás / revisa.
* it gets tough → se vuelve difícil (get + adjetivo = cambio de estado).
* that many → tantos.
* both...and → tanto...como (expresión fija).
* came from → provino / vino de.
* parameters → parámetros.
* notes → notas / anotaciones.
