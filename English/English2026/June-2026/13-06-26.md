Palabras y conceptos aprendidos

* supplied → suministrado / proporcionado.
* tune → afinar / ajustar.
* interface → interfaz (también puede usarse como verbo: interactuar con).
* boldface → negrita (estilo tipográfico).
* forward → adelante / siguiente.
* surrounding → circundante / que rodea.
* higher up → más arriba / en una posición superior.
* search path → ruta de búsqueda (lista de directorios donde MATLAB busca archivos).
* back and forward buttons → botones de atrás y adelante (navegación en interfaz).
