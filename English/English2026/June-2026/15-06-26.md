Today I started reading The C# Player's Guide, which will be my main reading material going forward. The book covers C# programming concepts explained in an informal and humorous style, with much more text per page than the MATLAB documentation I finished previously.

Some structures I found difficult:

* integer division drops remainders while floating-point division does not
* you may still be wondering when to use one type over another
* which is where the name comes from
* I'm not going to bother writing it out myself
* But C# delineates ints from bools because conflating the two is a pathway to lots of common bug categories
* that sticks around while your program runs but is wiped out when your program closes or the computer is rebooted

The main difficulty was the mix of informal English with technical vocabulary. Unlike MATLAB, this book uses humor, metaphors, contractions and idiomatic expressions constantly, which requires a higher level of reading comprehension beyond just knowing the technical terms.

Words and concepts learned

* retrieve → recuperar / obtener.
* tend → tender / soler (ej: tends to = suele).
* delineates → distingue / delimita.
* bother → molestarse en / tomarse la molestia de.
* deserve → merecer.
* borrow → tomar prestado.
* cram → abarrotar / meter a la fuerza.
* bring → traer.
* chop → cortar / trocear.
* sticks around → permanece / se mantiene (phrasal verb).
* come back → volver / regresar.
* we have seen → hemos visto (presente perfecto).
* comes from → proviene de / viene de.
* if left unhandled → si se deja sin manejar.
* spot → detectar / identificar (como verbo).
* glance → vistazo / mirada rápida.
* handful → puñado / pequeña cantidad.
* rounding → redondeo.
* toward → hacia.
* wiped → borrado / eliminado.
* meant → significaba / quería decir (pasado de mean).
* grown → crecido (participio de grow).
* somehow → de alguna manera.
* too → también / demasiado.
* suddenly → de repente / de golpe.
* regardless → independientemente / sin importar.
* merely → simplemente / meramente.
* heavily → fuertemente / en gran medida.
* meaningful → significativo / con sentido.
* tricky → complicado / engañoso.
* capable → capaz.
* stolen → robado (participio irregular de steal).
* meaningless → sin sentido / carente de significado.
* leftover → sobrante / residuo.

Reflection

Today was a very productive session. I started a new book entirely in English and managed to read a significant amount while learning a large number of new words.

The C# Player's Guide is noticeably denser in text per page compared to the MATLAB documentation, which makes it more demanding in terms of sustained reading. However, the informal and humorous tone makes it more engaging and easier to stay focused.

One thing I noticed is that many of the words I learned today are general English vocabulary rather than purely technical terms. This means the book is also helping me expand my everyday English beyond the technical register I built with MATLAB.
