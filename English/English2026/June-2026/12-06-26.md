Palabras y conceptos aprendidos

* as well as → así como también / además de.
* improve → mejorar.
* meet → cumplir / satisfacer (ej: meet a requirement = cumplir un requisito).
* undock → desacoplar (dock + prefijo un-).
* Laying Out → distribución / organización (de elementos en una interfaz).
* tuning → ajuste / optimización (ej: performance tuning).
* response → respuesta.
* callbacks → funciones de retorno de llamada (se ejecutan cuando ocurre un evento).
* sliders → controles deslizantes (elementos de interfaz gráfica).
* programmatically → de forma programática / mediante código.
* greatly → enormemente / considerablemente.
* improving → mejorando.
* Arranging → organización / disposición.
